# Gleneagle Arena homepage V2

Static homepage prototype for Gleneagle Arena. Open `index.html` in a browser to preview it. The package includes the image assets, fonts, scripts and a silent concert clip. The clip is an excerpt from the [Gleneagle Killarney homepage film](https://www.gleneaglekillarney.ie/). The design uses TT Commons Pro when installed and the bundled Lato webfont as a fallback.

## Publish on GitHub Pages

1. Extract the ZIP and commit its contents at the root of the repository. Keep `assets/`, `v2/` and the `.nojekyll` file next to `index.html`.
2. Open **Settings → Pages** in the repository. Under **Source**, choose **Deploy from a branch**.
3. Select the branch that contains these files and the **/(root)** folder, then click **Save**.

There is no build step. The preview homepage is static. The event search submits to the live Arena site and event, accommodation and newsletter links use their public destinations.

[GitHub Pages publishing documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
